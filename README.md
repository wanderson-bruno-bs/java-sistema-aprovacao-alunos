# Sistema de Aprovação de Alunos

Projeto desenvolvido em **Java** para calcular a média de três notas e informar a situação acadêmica de um aluno.

##  Funcionalidades

- Cadastro do nome do aluno.
- Leitura de três notas.
- Cálculo automático da média.
- Classificação do resultado:
  - **Aprovado:** média maior ou igual a 7.
  - **Recuperação:** média entre 5 e 6,9.
  - **Reprovado:** média inferior a 5.

1. Clone ou baixe este repositório.
2. Abra o projeto em uma IDE Java.
3. Execute o arquivo `src/Main.java`.
4. Informe o nome do aluno e suas três notas no console.

## Objetivo

Praticar fundamentos de programação Java, como entrada de dados com `Scanner`, variáveis, operadores e estruturas condicionais (`if`, `else if` e `else`).
